# FunHub Platform

Backend API for the FunHub platform.

## Tech Stack

- NestJS
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Swagger API Documentation

## Features

- User Registration & Login
- JWT Authentication
- User Profile Management
- Business Registration
- Business CRUD
- Ownership Authorization
- Prisma Database Integration

## Getting Started

```bash
npm install
npm run start:dev
```

The API will start on:

http://localhost:3000

Swagger documentation:

http://localhost:3000/api
